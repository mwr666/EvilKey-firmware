# Firmware configuration export

Manager exports the separately supplied firmware sources; its EXE does not
embed them. Put the extracted `firmware/` folder beside the EXE or select it
when prompted. Configuration export does not flash the device.

Use **EvilKey.cmd → 7** to build the exported project and **11** to install
through the guarded uploader. See [installation information](INSTALLATION_INFORMATION.md)
and [Build and flash](../docs/BUILD_AND_FLASH.md).
