EvilKey R29 - safe microSD test

1. Copy the duckyscripts folder to the root of the microSD card.
2. Connect EvilKey to a test computer you own or are authorized to use.
3. Open a plain text editor and place the cursor in an empty document.
4. In USB Tool, select R29_Ducky3_HID_Smoke.duck and press RUN.

This script does not launch a terminal or PowerShell, download anything, read
files, or exfiltrate data. It tests ATTACKMODE HID, STRINGLN, VAR, WHILE,
RANDOM_SPECIAL, and RANDOM_CHAR.
